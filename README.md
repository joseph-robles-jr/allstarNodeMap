# allstarNodeMap
A JavaScript module that renders a simple map of directly attatched AllstarLink Nodes

import the module and import the allstarNodeMap function. 

```
import { allstarNodeMap } from "../jsModules/allstarNodeMap/allstarNodeMap.js";

async function main(){
    await allstarNodeMap(YOUR_NODE_NUMBER_HERE,ID_OF_CONTAINER_TO_HOLD_HTML); 
}

main();
```
